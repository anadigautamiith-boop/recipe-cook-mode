Test lab

This page sends a set of real cooking videos through the live app and records what each one cost, how long it took and what came out. A computer can count steps. Only a cook can say whether a recipe works, so each video has a box for your rating.

1. Check the setup

Run these once after you add the key. They tell you what is wrong before you spend anything on a full run.

2. The test videos

Each run is a real request, so it costs a little and counts toward the hourly limit. Paste your own links over any of these, and rename a row if the video is not what its name says.
